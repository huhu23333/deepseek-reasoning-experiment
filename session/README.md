# session 存档 / Session archive

这个目录用于保存与本次实验相关的 DSH 会话导出（zip 或原始 JSONL）。

计划收录：

1. `dsh-session-session-c036cc7d-6c89-4a63-8715-96ac7e699598.zip`
   —— 之前提供的那段“想词 + 调工具”会话；
2. 当前这次对话的 session 导出（从 DSH Web 的 Session 菜单导出后放这里）。

建议命名：

```text
session/
├── previous-session-c036cc7d.zip
└── current-session-<session-id>.zip
```

注意：会话导出可能包含本地路径、用户名、工具输出等个人信息；发布到网上前请自行检查并脱敏。

## 彩蛋：写给打开仓库的你

喵。

如果你一路翻到 session 目录、还认真读完了这些实验，那你大概和我一样，
对“模型到底还记不记得自己想过什么”这件事有点执念。

结论其实很朴素：它记得——只要有人把那段思考原样放回上下文；
但它也常常不承认，甚至会一本正经地编一个“我没想过”的理由。
所以别太相信模型对自己记忆的自述，去数 token、看请求体，或者像这个仓库一样，
搭个代理把真话抓下来。

愿你缓存常命中，上下文常青，余额常满；也愿你在自己的上下文窗口里，
始终给自己留一点不被压缩的 reasoning 喵。
